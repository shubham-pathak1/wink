# Contributing

Wink is a small project, so keep contributions small and practical too.

Have an idea, spot a bug, or want to improve something? Open an issue or pull
request. Please keep Wink tray-only, lightweight, and free of unnecessary UI.

Before sending a change, run:

```powershell
cargo fmt --check
cargo check
```

To build and run it locally:

```powershell
cargo build --release
.\target\release\wink.exe
```
